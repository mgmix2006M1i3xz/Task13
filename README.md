Домашнее задание к работе номер 13

Условие задачи:
Напишите программу, которая во введенной пользователем строке (используйте fgets() для чтения строки с пробелами) находит самое длинное слово и выводит его на экран.

Указание: Слова в строке разделены пробелами. Знаки препинания располагаются сразу после буквы и за ними следует пробел. Необходимо корректно обрабатывать конец строки и не выходить за пределы массива.

1. Алгоритм и блок-схема.

Алгоритм:

1) Начало.
2) Ввод строки str через fgets.
3) Инициализировать max_len = 0, cur_len = 0, max_start = 0.
4) Цикл i от 0 до конца строки:
5) Если символ не пробел, не \n, не \0: cur_len++.
6) Иначе: если cur_len > max_len, обновить max_len и max_start = i - cur_len. Сбросить cur_len = 0.
7) Вывести подстроку от max_start длиной max_len.
8) Конец.

2. Реализация программы

#include <stdio.h>
#include <string.h>
#include <locale.h>

int main() {
    setlocale(LC_ALL, "RUS");
    char str[256];
    int max_len = 0, cur_len = 0;
    int max_start = 0;

    printf("Введите строку: ");
    fgets(str, sizeof(str), stdin); // Читает строку с пробелами

    int len = strlen(str);

    for (int i = 0; i <= len; i++) {
        // Если текущий символ не пробел и не конец строки
        if (str[i] != ' ' && str[i] != '\n' && str[i] != '\0') {
            cur_len++;
        } else {
            // Если слово закончилось, проверяем его длину
            if (cur_len > max_len) {
                max_len = cur_len;
                max_start = i - cur_len; // Запоминаем начало слова
            }
            cur_len = 0; // Сбрасываем счетчик для следующего слова
        }
    }

    printf("Самое длинное слово: ");
    for (int i = max_start; i < max_start + max_len; i++) {
        printf("%c", str[i]);
    }
    printf("\n");

    return 0;
    
}
